## [1.0.0] - 2025-11-13

### Added

-   Initial release of the Migraine Tracker Home Assistant add-on.
-   Light-sensitivity friendly UI with a dark, low-contrast theme.
-   Backend API with FastAPI and an encrypted SQLite database.
-   Frontend UI with Vue.js, including a dashboard, migraine logging form, and settings panel.
-   Weather data integration with Open-Meteo.
-   Home Assistant sensor integration for `sensor.migraine_current_status`.
-   Data import and export functionality in JSON format.
-   Calendar view for visualizing migraine history.
